# Frontend (ab M1)

Die M0-Dashboard-Oberfläche befindet sich zunächst direkt unter
[`extension/dashboard.html`](../extension/dashboard.html) und besteht aus
vanilla HTML/CSS/JavaScript ohne Build-Abhängigkeiten. Das erlaubt den
sofortigen Test als entpackte MV3-Erweiterung.

Nach erfolgreichem M0-Praxistest kann das UI in eine separate
**Vue 3 + Vite + TypeScript**-Anwendung überführt werden.
